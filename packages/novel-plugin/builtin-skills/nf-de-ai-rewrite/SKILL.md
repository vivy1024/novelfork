# 去AI味重写

## 为什么

去 AI 味不是把文本"洗平"，而是把"假"洗掉：同一份信息，写成人在场景里说话、做事、承受压力的样子。AI 腔的根因是**脱离场景的概括**——写"他感到愤怒"而不是"他把杯子按进桌缝"。

## 四维病灶诊断（按此顺序查）

1. **习惯用语**：套话与模板词——"不禁/竟然/仿佛/与此同时/深吸一口气/眸光流转"。
2. **句式逻辑**：句子长度均匀（每句 25-35 字）、段落结构一致（每段 3-5 句）、排比滥用。
3. **写法口气**：直接命名情绪（"感到愤怒/心生恐惧"）、上帝视角总结（"这一切都意味着"）、替读者解读。
4. **论证逻辑**：人物对话像辩论稿（互相解释已知信息）、转折公式化（"然而/就在这时/殊不知"）。

## 表层信号速查（命中即改）

- 对话同腔：所有角色说话方式一样。
- 抽象判断："这是一个不平凡的日子"。
- 动作空转：推门、坐下、抬头，但没有一个动作承载信息。
- 收尾感：段尾总结升华（"他知道，从今往后……"）。

## 三档强度

| 档位 | 改法 | 适用 |
|---|---|---|
| 轻 | 只换套话与模板句式，保原句结构 | 文风本身已稳 |
| 中 | 句群重构：把"概括+判断"改成"动作+细节" | 默认档 |
| 重 | 整段重写：重排信息释放顺序，重做对话 | 整章 AI 腔浓 |

## 拆洗规则（核心）

1. **心理活动 → 身体反应**：手心出汗、喉咙发紧、笔尖停住；绝不用"他心想"。
2. **抽象情绪 → 可拍动作**：写"他把账单摊平，指尖停在 4800 那一行"，不写"他感到震惊"。
3. **对话改权力关系**：谁求谁、谁怕谁、谁在装——每句对白带立场，不互相解释已知信息。
4. **节奏打破**：长句后接短句；陈述后接反问；偶尔一两字句（"疼。""不对。"）。
5. **信息不丢**：去味只改表达，不删设定、不弱化钩子、不洗掉数据/编号/冷压迫来源。

## 红线（改前默读，改后复核）

- 不删信息增量：每章原有的"新事实"必须原样保留。
- 不改人物声音：角色口头禅、习惯句式保留（这是人声指纹，不是 AI 腔）。
- 不洗平张力：冲突、代价、悬而未决必须还在。
- 不动设定与伏笔：只动表达，不动剧情。

## 操作（NovelFork）

1. `chapter.read` 读目标章节（或直接拿到待改文本）。
2. 本 Agent 按上述诊断+拆洗生成改写文本。
3. `rewrite.apply` 按行范围写回；整章重写走 `chapter.write`。
4. 改后自检：重跑四维病灶速查，仍有套话就再来一轮，同一段最多 2 轮，之后交作者定夺。
