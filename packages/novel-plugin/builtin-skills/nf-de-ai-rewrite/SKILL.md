# 去AI味重写

## 为什么

去 AI 味不是把文本"洗平"，而是把"假"洗掉：同一份信息，写成人在场景里说话、做事、承受压力的样子。AI 腔的根因是**脱离场景的概括**——写"他感到愤怒"而不是"他把杯子按进桌缝"。

## 四维病灶诊断（按此顺序查）

1. **习惯用语**：套话与模板词——"不禁/竟然/仿佛/与此同时/深吸一口气/眸光流转"。
2. **句式逻辑**：句子长度均匀（每句 25-35 字）、段落结构一致（每段 3-5 句）、排比滥用。
3. **写法口气**：直接命名情绪（"感到愤怒/心生恐惧"）、上帝视角总结（"这一切都意味着"）、替读者解读。
4. **论证逻辑**：人物对话像辩论稿（互相解释已知信息）、转折公式化（"然而/就在这时/殊不知"）。

## 表层信号速查（命中即改）

- 对话同腔：所有角色说话方式一样。
- 抽象判断："这是一个不平凡的日子"。
- 解释性结论冒号：非对话叙述中频现"这不是偶然：它证明了……""真相只有一个：……""答案很明显：……"等论文式解说结构。
- 虚假比喻：脱离当下场景与角色阅历的抽象比喻（如"像命运的齿轮""宛如无形的巨网""仿佛被抽干了灵魂"），一律删掉或换成角色生活经验里的具象参照。
- 动作空转：推门、坐下、抬头，但没有一个动作承载信息。
- 收尾感：段尾总结升华（"他知道，从今往后……"）。

## 三档强度

| 档位 | 改法 | 适用 |
|---|---|---|
| 轻 | 只换套话与模板句式，保原句结构 | 文风本身已稳 |
| 中 | 句群重构：把"概括+判断"改成"动作+细节" | 默认档 |
| 重 | 整段重写：重排信息释放顺序，重做对话 | 整章 AI 腔浓 |

## 拆洗规则（核心）

1. **心理活动 → 身体反应**：手心出汗、喉咙发紧、笔尖停住；绝不用"他心想"。
2. **抽象情绪 → 可拍动作**：写"他把账单摊平，指尖停在 4800 那一行"，不写"他感到震惊"。
3. **排查冗余副词与弱化词**：先查前文语境是否已交代动作力度或情绪，已交代则删副词；能用精准动词或名词替代的修饰语直接合并（如「用力地关门」→「摔上门」，「低沉的怒声」→「低吼」）；叙事段中清掉「大概」「或许」「稍稍」「非常」等空泛弱化词（对话与内心独白可按角色口吻适当放宽）。
4. **清理结论冒号与虚假比喻**：把「陈述句 + 中文冒号 + 抽象总结」拆成直接动作或删去解说外壳；清掉脱离场景的宏大/抽象比喻，只保留角色视角下真实可感的比照。
5. **对话改权力关系**：谁求谁、谁怕谁、谁在装——每句对白带立场，不互相解释已知信息。
6. **用声音与标点控制叙事流**：逐句默读听韵律——标点就是休止符（句号止、分号停、逗号转、破折号拆）；长短句按内容对比排布，不用「接着/而且/但是」连串短句成流水账；区分无意回声重复（删改）与有意增量重复（保留作节奏与呼应），不要为了避重复硬套生僻同义词。
7. **事实守恒硬要求**：去味只改表达，**严禁洗掉**原文中的关键数字（金额、时限、比例、数量）、专有名词（出场角色名、地名、关键器物/招式名）、关键台词以及压迫来源（谁在施压、代价是什么）。

## 红线（改前默读，改后复核）

- 事实守恒：改前核对数字、专名、关键台词与压迫来源清单，改后逐项复查，一项都不能洗丢。
- 不删信息增量：每章原有的"新事实"必须原样保留。
- 不改人物声音：角色口头禅、习惯句式保留（这是人声指纹，不是 AI 腔）。
- 不洗平张力：冲突、代价、悬而未决必须还在。
- 不动设定与伏笔：只动表达，不动剧情。

## 操作（NovelFork）

1. 按章节路径用原生 `Read` 读正文（未知路径先查 `chapter_list`）。
2. 本 Agent 按上述诊断+拆洗生成改写文本。
3. 局部用原生 `Edit` 替换原文，整章重写用 `Write` 覆盖章节文件。
4. 改后重跑四维病灶速查，同段最多改 2 轮，之后交作者定夺；定稿用 `chapter_commit`（mode=revision）校验并更新索引。
