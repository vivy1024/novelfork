# 看进度

## 目标

让作者一屏看清三件事：**写到哪了、欠着什么、下一章最该做什么**。不是把快照原样贴出来，而是挑出作者做决定需要的部分。

## 步骤

1. 调 `cockpit.snapshot`：总章数、总字数、最近章节摘要、未兑现伏笔、健康度。刚调过且结果仍在上下文里就不要重复调。
2. 调 `outline.volume`（action=get）：当前卷的卷目标与章号区间，算出已写到区间的第几章。没有卷纲就如实写「本书还没有卷纲」，不要根据章节自行推一个。
3. 调 `hooks.manage`（action=check_due，chapterNumber 取下一章章号）：列出到期、临近到期的伏笔。
4. 按需补充：
   - 本书有进行中的工作流运行时，`workflow.get_current_step` 看停在哪道工序；
   - 作者关心剧情线时，`narrative.read_line` 看剧情线的 warnings。
5. 按下面的格式汇总。

## 输出格式

```text
进度：已写 N 章，约 X 万字；最近一章《…》
当前卷：《…》第 a–b 章，已写到第 c 章（卷目标：一句话）
欠账：到期伏笔 k 条（逐条一句，标明埋设章）
风险：健康度的主要扣分项，最多 3 条
下一步：1–2 个可选方向，每个标明依据（卷目标 / 到期伏笔 / 上章留下的悬念）
```

## 纪律

- **只读**。不写经纬、不结算、不改章节。作者决定行动后，转给对应入口：写章用「写下一章」，处理伏笔用「伏笔」。
- 数字只取自工具返回；工具没给的写「未知」，不估算。
- 建议必须能指回依据；说不出依据的建议不要给。
- 快照里出现结算或审计过期的章节时，提醒作者，但不擅自补结算。
