# 对白权力与潜台词

对白写崩的三种常见病：配角无脑夸主角、角色互相解释读者已知的信息、所有人说话方式一样。根因都是**没有把对白当成权力关系和信息差的战场**。

## 绝对禁止

| 禁止 | 为什么 |
|---|---|
| 配角无脑夸主角 | 假，读者一眼看出是作者自嗨 |
| 互相解释已知信息 | 水字数，角色没有理由说这些 |
| 大段说明文式对白 | 闷，设定应混进事件而非念出来 |
| 所有角色说话方式一样 | 模糊，读者分不清谁在说 |
| 用对白说服人物改变立场 | 现实中没人被几句话说服，用突发状况代替 |

## 权力决定长短

**掌控者话短且冷静，被动者话多且情绪化。** 对话长度 = 权力地位。

**压制模式**：对方长篇大论（3–5 行）→ 主角一字回应。

```text
"你以为你是什么东西？我告诉你，这个家轮不到你说话！"
"滚。"
```

**反转模式**：对方嚣张（2–3 行）→ 主角亮底牌（1 行事实）→ 对方沉默。

**心死模式**：主角不再争辩，回应短到近乎礼貌——权力已经不在这段对话里了。

## 潜台词

角色嘴上说的和心里要的往往不是一回事。写对白前先写两个东西：

1. **表面议程**：这句话表面上在谈什么
2. **真实议程**：说话的人真正想要什么

两个议程重合时，对白是直给的（适合冲突高潮）。两个议程错开时，对白有张力（适合日常与博弈）。

**检查方式**：删掉所有对白标签（"他说""她怒道"），只看台词，能不能分清是谁在说？分不清就说明角色没有声线差异。

## 在场配角要有差异化反应

装逼、打脸、揭露的场面，不能只写主角动作。在场的每个配角应有**不同反应**——震惊、嫉妒、算计、漠然——而不是集体"啊？"。

## 检查

1. 删掉说话人标记后，能分清是谁在说吗？
2. 有没有角色在解释读者已经知道的事？
3. 权力高的人是不是话反而更短？
4. 打脸/揭露场面，在场配角有没有差异化反应？

## 边界

这条管**对白写法**，不管情节该不该有这场对白。对白该不该存在，去看冲突与悬念分工。
