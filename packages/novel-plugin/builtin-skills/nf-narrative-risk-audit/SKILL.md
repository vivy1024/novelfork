# 叙事风险审计

这套审计查的**不是词汇**，是叙事结构。禁用词、套话、标点由 `story-deslop` 与本地
filter 引擎负责；这里只回答一个问题：**人物的变化有没有过程，叙事有没有说太满。**

## 为什么必须零继承

写正文的模型知道自己想表达什么，所以它读自己的稿子时会自动把缺失的过程补上——
它看到「他决定背叛」，脑子里有完整的动机链，于是判断这句成立。读者没有那条链。

因此审计必须由**另一个不知道任何前情的子代理**执行。它只拿到正文，看不到大纲、
人物档案、作者意图、写作过程、上一轮审计结论，也不知道你希望它发现什么。它读不懂
的地方，就是读者读不懂的地方。

这条隔离是本 skill 的全部价值来源。破坏隔离，审计立刻退化成自我确认。

## 执行协议

### 1. 启动零继承子代理

```
Agent(
  subagent_type: "explore",
  prompt: <本文件「子代理任务模板」整段 + 当前章正文>
)
```

硬约束：

- **只传正文与风险卡**。不传大纲、卷纲、人物档案、经纬条目、叙事记忆、章节蓝图、
  作者指示、上一版正文、历史审计报告、你自己的怀疑位置。
- 不在 prompt 里暗示答案。禁止出现「重点看第三段」「我觉得动机不足」这类引导。
- 不告诉它这是第几章、前面发生过什么。它应该像翻开一本书的中间一页。
- 无法启动子代理时，标记「自审降级模式」并说明结论可信度下降，**不得**声称完成了
  独立审计。

### 2. 收下证据，自己判断

子代理只产出候选证据。是否采纳由主代理按正文判断：

- 命中项确实缺过程 → 重建缺失的那一环，不是加解释。
- 命中项其实是刻意留白（悬念、限知视角）→ 记为不采纳并说明理由。
- 拿不准 → 标 `[需复核]` 交给作者，不擅自改。

### 3. 改完不重跑同一个子代理

复核必须换一个新的零继承子代理。读过旧稿的代理已经有了前情，隔离失效。

## A 路：用结论替代过程

作者把「发生了什么」写成了「结果是什么」。读者拿到判决书，没看到审判。

| 编号 | 风险 | 命中判据 |
|---|---|---|
| A1 | 背景标签跳跃 | 人物的身份、立场或能力靠一句交代确立，正文里没有任何行为验证过它 |
| A2 | 情绪只命名不作用 | 出现情绪词，但该情绪没有改变人物接下来的动作、选择或与他人的关系 |
| A3 | 人物共用作者脑 | 多个角色的判断力、信息量、说话方式趋同，像同一个人在分饰多角；或人物替作者把剧情推到正确方向 |
| A4 | 描写后加总结盖章 | 已经用动作/细节呈现过的东西，紧接着又用一句评价或定性重复一遍 |

## B 路：叙事过满

每一步都给了答案，人物没有真正的选择，处境不变。

| 编号 | 风险 | 命中判据 |
|---|---|---|
| B5 | 信息过快就位 | 悬念刚立起来就被解答，读者来不及产生疑问 |
| B6 | 细节出现即功能化 | 物件/人物一登场就立刻发挥作用，没有任何闲置期 |
| B7 | 同一转变说两遍 | 一个变化在不同位置被重复确认，第二次没有新增信息 |
| B8 | 结尾清单式结算 | 章末逐项交代每条线的状态，像结账 |
| B9 | 验线走廊 | 连续多步只在公布答案：人物没有做出新选择，处境、关系、代价都没变 |

B9 是最难自查的一项，也是「读着不累但读完没印象」的主要成因。判据不是「有没有信息
量」，而是**人物在这段里有没有付出代价或失去选项**。

## 子代理任务模板

以下整段作为子代理 prompt 的开头，后面直接接正文：

---

你是一名资深中文小说编辑，正在审读一段你完全不了解背景的正文。你不知道这是第几章、
前面发生过什么、作者想表达什么，也不需要知道。

只做一件事：按下列九项风险卡逐项检查，命中就摘出原文证据。

**A 路（用结论替代过程）**
- A1 背景标签跳跃：身份/立场/能力只靠交代确立，正文无行为验证
- A2 情绪只命名不作用：情绪词没有改变后续动作、选择或关系
- A3 人物共用作者脑：多个角色判断力与说话方式趋同，或人物替作者把剧情推向正确方向
- A4 描写后加总结盖章：已呈现过的内容又被一句评价重复定性

**B 路（叙事过满）**
- B5 信息过快就位：悬念刚立就被解答
- B6 细节出现即功能化：物件/人物登场即发挥作用，无闲置期
- B7 同一转变说两遍：变化被重复确认且无新增信息
- B8 结尾清单式结算：章末逐项交代各线状态
- B9 验线走廊：连续多步只公布答案，人物无新选择、处境与代价不变

**输出格式**，每条一行：

```
[编号] 「原文摘录（≤40字）」— 命中理由（一句话）
```

**硬约束**

- 只报告，不改写，不给改写方案。
- 每条必须带原文摘录。没有摘录的判断不要输出。
- 不确定的不报。宁可漏，不可编。
- 不评价文笔好坏、不评价 AI 味、不做文学赏析、不猜作者意图。
- 全部九项都没命中就回一行：`未命中`。

---

## 边界

- 本 skill 不改正文，不写文件，不动经纬与叙事记忆。
- 不产出分数。九项是定性判据，凑成百分制只会制造虚假精度。
- 与 `story-deslop` 不重叠：那边管词汇与句式，这边管叙事结构。两者都过才算干净。
- 命中数量不是质量指标。刻意留白的作品会命中 B5/B6，那是风格不是缺陷，由作者定夺。
