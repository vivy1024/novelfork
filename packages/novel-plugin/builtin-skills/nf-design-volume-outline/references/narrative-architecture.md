# 叙事架构与中盘推演速查卡

用于分卷大纲设计与中盘卡顿诊断；核心原则须放回具体题材语境使用，不作僵化公式。

## 1. 「价值+原因」主控思想检验

- 空泛主题词（如「复仇」「成长」「正义」）无法指导删改；真正的主控思想必须写成「最终落定的正/负价值 + 促成该转化的单一主导原因」。
- 用法：在卷末高潮落定后反推主控思想，以它为筛子——凡偏离该主导原因、虽有趣却散焦的支线果断裁剪；在卷内让正面思想与负面「反思想」交替交锋直至对决。

## 2. 四阶「负面之墙」（对抗力量自检）

当一卷显得平庸乏力时，不要堆砌主角光环，而应沿核心正面价值核查对抗力量是否走到终点：

1. **正面价值**：如公正、信任、生存。
2. **相反价值**（略带负面）：不公平、猜忌、受困。
3. **矛盾价值**（直接对立）：非正义、背叛、死亡威胁。
4. **否定之否定**（质与量双重恶化，生活两负不得正）：制度性专制压迫、连自我信任都被瓦解、生不如死的系统性绞杀。

> 限制：不必死板按顺序逐幕递进，开篇直入否定之否定亦可，但全卷至少须在一处触达负面终点，随后方能以悲剧收束或回到更有分量的正面价值。

## 3. 打破中段停滞：冰山对手与递增揭露

- **冰山对手**：反派不一次亮出全部层级与手段，前期以隐秘反击让主角按旧计划必然受挫。
- **递增揭露**：每次关于对手、盟友或真相的新揭露都必须比前一次强度更高，并迫使主角**根本改变策略**（河道转弯），而不是原地重复相似动作。
- **唯一「看似落败」**：挫折可以多次，但令主角看似穷途末路的毁灭性低谷一卷只设一次（多在 65%–75%），紧接二次揭露点燃背水一战的驱动力。

## 4. 视觉子故事世界（空间外化结构）

把大地图切分为绑定结构步骤的子场域，避免设定说明书化：
- 开篇子世界：物理化主角的受困、弱点或恐惧；
- 对手居所/势力区：直观展现其攻击主角弱点的力量；
- 看似落败与终极对决：刻意反常识收窄空间（封闭、逼仄、退无可退），以「压力锅效应」放大爆发力。
