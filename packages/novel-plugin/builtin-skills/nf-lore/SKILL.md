# 设定

## 各类信息放在哪

| 信息 | 位置 | 工具 |
|---|---|---|
| 人物、地点、势力、规则、物品、术语的设定 | 经纬静态条目 | `lore.read` / `lore.write` |
| 角色之间、势力之间的关系及其变化 | 经纬关系条目 | `lore.relate` |
| 随剧情推进的字段（冲突阶段、时间线状态等） | 经纬动态条目 | `lore.progress` |
| 某章发生了什么、谁知道了什么 | 叙事记忆 | `memory.read` / `memory.events` |

章节里新发生的事实先进叙事记忆，不要直接写成经纬正典。

## 查设定

1. 先用 `lore.read`：scope=brief 看全局，scope=category 读某一类，scope=search 按关键词找。
2. 作者问「为什么写作时没用上这条设定」，用 `jingwei.audit` 查它是不是草稿、待审或被停用了。
3. 回答时注明条目标题，方便作者去经纬里找。

## 补设定、改设定

1. **先读后写**。写之前用 `lore.read` 找有没有同名或相近的条目，有就更新，不另建一条重复的。
2. **给草案**。把要写入的内容列给作者：分类、标题、正文、层级，以及改了哪几处。
3. **查冲突**。新设定可能和已写章节矛盾时，用 `memory.search` 查相关关键词，把可能冲突的章节告诉作者。
4. **作者确认后写入**，用 `lore.write`：
   - 作者亲口定下的设定：status 默认即可；写入正典（layer=canon）或规则类时必须带 reason，以及 source 或 evidence。
   - 从正文或拆书里提取出来的：layer=dynamic、status=needs-review，等作者审过再升级。
   - 一次补多条时用 entries，最多 20 条。
5. 关系变化用 `lore.relate`，同一对角色的多次变化会更新同一条，不用每次新建。

## 改错与退役

- 非正典的错条目可以删除（action=delete）。
- 正典条目不能删，也不要靠改层级绕过：错了或过期了用 action=retire，写明 reason，并带 confirmCanonEdit=true。退役后它不再进入写作上下文，历史仍保留。

## 纪律

- 不把作者没确认的推测写进经纬。
- 不把诊断结果、市场资料、审阅意见写成设定。
- 设定描述写事实，不写「必须在正文中出现某某词」之类的要求。
