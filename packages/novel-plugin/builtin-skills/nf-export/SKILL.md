# 导出

## 先说清楚能做什么

| 作者要的 | 能做到的 | 工具 |
|---|---|---|
| 某几章正文 | 按章读出，整理成干净的纯文本放在回复里，作者自己复制 | `chapter.list` + `chapter.read` |
| 投稿前自检 | 敏感词线索、AI 味线索、正文完整性与连续性证据 | `publish.check` |
| 卷纲 | 读出分卷与章号区间；本书目录下的 `story/volume_outline.md` 是卷纲的导出视图 | `outline.volume`（action=get） |
| 叙事记忆 | 以 JSON 导出事实、事件等记录 | `memory.export` |

**做不到的**：小说工具不能生成 txt、docx、epub 等文件，也不能把整本书打包成一个文件或完整备份。作者要文件时，如实说明这一点，建议从作品目录的 `chapters/` 直接取章节文件。

## 导出章节正文

1. `chapter.list` 列出章节，和作者确认范围（第几章到第几章）。
2. 逐章 `chapter.read`。一次回复放不下时分批给，每批标明章号范围，并告诉作者还剩几批。
3. 整理格式：
   - 每章以「第 N 章 标题」开头；
   - 去掉章节元信息与工作标记，只留正文；
   - 段落之间空一行，不改动正文用字。
4. 不润色、不删改、不补写。发现明显问题（缺章、重复段落）时单独列出，让作者决定。

## 投稿前自检

1. 调 `publish.check`：platform 按作者要投的平台选，不填则按本书平台设置；可以只查某一章或某个章号范围。
2. 把高风险线索放在最前面，每条附正文定位。
3. 说明这是本地线索，不等于平台审核结论。
4. 需要按平台调整排版时（如短段落、强章末），本书启用了对应的平台技能就按它处理，例如「番茄版输出」。

## 导出卷纲与叙事记忆

- 卷纲：`outline.volume` action=get，整理成「卷名 / 章号区间 / 卷目标」列表。
- 叙事记忆：`memory.export`，kind 按作者需要选择。这是给作者查阅或迁移用的数据，不要当成设定文档交出去。

## 纪律

- 导出只读，不修改任何章节、经纬或记忆。
- 不把导出内容写进其他书籍。
- 说不清能不能做到的，先查工具返回，再回答作者。
