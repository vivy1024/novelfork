# 元信息泄漏扫描

模型在写作时同时在"思考写作"，于是工作语言会渗进正文。这类词在故事世界里不存在，读者一眼就出戏。

## 扫什么

检查**标题行以外**的正文，命中下列表达就要改写：

- 章节指代：`第X章`、`上一章`、`上章`、`前一章`、`本章`、`这一章`
- 文本结构：`前文`、`后文`、`细纲`、`大纲`
- 创作术语：`伏笔`、`铺垫`（作为写作手法而非角色心理时）
- 读者指涉：`读者`、`观众`（角色并非在谈论真实读者时）

## 怎么改

不是删掉，是**换成角色当下可感知的东西**：

| 泄漏写法 | 改成 |
|---|---|
| 正如上一章所说 | 就像那天夜里他答应过的 |
| 这一章的重点是 | （直接写事件，不作说明） |
| 这是为后文埋的伏笔 | （只写事件本身，不点破用意） |
| 让读者感到紧张 | （写出让人紧张的具体细节） |

原则：**把工程语言换成故事内的时间、物件、动作或感受。**

## 例外

只有两种情况可以保留：

1. 角色在故事世界内**真实阅读或讨论**一本带"第X章"的书。
2. 角色**真实身为作者或读者**，并在谈论这个身份。

例外之外一律改写。判断标准是：这句话在故事世界里成立吗？不成立就是泄漏。

## 边界

这条只管**语言层面的泄漏**，不管情节质量。发现泄漏就地改写，不要记成待办留到下一章。
