# 番茄版输出

番茄是免费阅读平台，稿费与**完读率**强相关，不是与字数强相关。所以这里的一切调整都指向一件事：让读者把这一章读完。

## 硬性节奏

- **前 300 字必须有冲突或爆点。** 首章尤其严格——读者划走只需要三秒。
- **每 300–800 字一个抓点。** 抓点可以是反转、冲突升级、信息揭露、情绪刺激。
- **章末强钩子。** 不是留白，是留一个明确的未解问题。

## 文本形态

**段落要短。** 三到四行一段，长段落在手机屏幕上是劝退信号。

**多用短句。** 长复句拆开。对白比叙述更容易读下去。

**多给感官和情绪，少给设定。** 需要交代设定时，拆成小块混进事件里，不要整段解释。

## 避免

- 开篇大段世界观铺陈
- 自我陶醉的环境描写
- 一章里塞进过多新名词
- 章末平淡收束（"他睡了过去"这类）

## 检查

改完后逐条问：

1. 前 300 字里有没有一个能一句话说清的冲突？
2. 通读一遍，最长的一段超过五行吗？
3. 章末那句话，会让人想点下一章吗？
4. 这一章有没有超过三个读者第一次见的专有名词？

## 边界

这套只管**平台适配**，不改情节。如果情节本身没有冲突，调整段落长度救不回来——那要回到章节蓝图去改。

> 平台机制与读者偏好参考自 lornshrimp/Lorn.NovelWriteSkills 的平台输出经验总结。平台规则会变，以官方公告为准。
