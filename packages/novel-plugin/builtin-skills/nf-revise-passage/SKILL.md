# 改这段

## 目标

局部修改最怕两件事：改着改着把前后文也动了；改完的段落和上下文接不上。本技能只做一件事——**把指定的那一段改好，并且只改那一段**。

## 第一步：锁定范围

1. 作者给的是章号加引文，或写作台里选中的文字。按章节路径用原生 `Read` 读正文（未知路径先查 `chapter_list`），找到起止行号。
2. 引文在章里出现多次、或找不到时，先问作者是哪一处，不要猜。
3. 向作者复述：「第 N 章第 a–b 行，从『……』到『……』」。

## 第二步：弄清要改什么

把作者的话归到一种或几种意图，拿不准就问：

| 意图 | 做法 |
|---|---|
| 压缩 | 删重复信息、解释性肿块与空转过场，大胆做时间/信息跳跃，保留动作与对白的推进 |
| 扩写 | 补感官细节、粗略类比与反应过程，不新增剧情事实、不写成参数使用说明 |
| 换语气 | 调措辞、标点停顿、长短句对比与分段边界，修正修饰语错位，事实不变 |
| 改对白 | 按人物身份和当下处境重写声口；直白摊牌太假时引入「第三者」改为三边对话 |
| 去 AI 味 | 按「去AI味重写」病灶表拆洗套话、心理直写与冗余副词，用精准动词承载力度 |
| 改情节 | 明确告知这会改变事实（表层润色与深层改因果分开处理），落盘后重新结算本章 |

## 第三步：装载必要的上下文

- 改动涉及人物言行：`jingwei_read` 读出场人物的设定。
- 改动涉及前文事实（谁知道什么、东西在哪）：`memory_read`（purpose=revise）核对。
- 纯文字层面的修改不必装载，别为改一句话读半本书。

## 第四步：给出对照

```text
【改前】第 a–b 行原文
【改后】新文本
【改了什么】一到三条，说明每处改动的理由
```

新文本要守住：视角人物、时态与人称、专有名词写法、与上一句和下一句的衔接。改完读一遍前后各两行，确认接得上。

### 防原地换词升级规则

- 局部改稿最容易掉进「同义词换皮」陷阱——换了几个词或调了标点，原句的毒句式、解释腔或平淡骨架却原封不动。
- **同段连续两次局部微调仍未消除目标病灶时，立即停止同义词替换**：明确记下这一拍的**事件目的**与**人物起止状态**（含数字、专名、关键台词与压迫来源），丢弃原句骨架，按新句序与具体动作整段重写。

## 第五步：落盘

作者确认后，用原生 `Edit` 精确替换锁定的原文；插入时保留原行，只在其后补入新段。再用 `chapter_commit`（mode=revision）校验并更新索引。

- 作者未确认时，划词只用 `chapter_propose_selection` 给候选，不改正文。
- 改动超出一段、变成整章重写时，停下来请作者重新确认范围。
- 改了剧情事实而仍需重结算时，用 `memory_settle` 传 chapterNumber。
