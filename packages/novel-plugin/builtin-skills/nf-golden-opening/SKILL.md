# 黄金三章

前三章决定留存率。它们的任务**不是**把世界观交代清楚，是让读者想看第四章。

## 三章各自的任务

**第一章：给一个具体的困境。**
主角是谁不重要，主角**此刻卡在哪**才重要。开篇三百字内要出现一个读者能立刻理解的麻烦——被退婚、被夺功、明天就要死。抽象的"身世成谜"不算麻烦，它没有紧迫感。

**第二章：给一个转机，但要付代价。**
主角开始动手解决问题，并露出他区别于常人的那一点（金手指、性格、见识）。关键是**这个转机必须有代价**——白得的东西读者不信，也不产生期待。

**第三章：给一个更大的问题。**
第一个麻烦解决或缓解的同时，露出后面更大的东西。读者读完第三章要产生的念头是"这事没完"，不是"这事解决了"。

## 开篇必须避免的

**不要用世界观开场。** 前三章不需要读者理解修炼体系有几个境界。设定在需要时给，一次给一点。

**不要用回忆开场。** 读者还不认识这个人，不会关心他三年前经历了什么。

**不要让主角一开始就无敌。** 无敌意味着没有困境，没有困境就没有理由继续读。

**不要在第一章塞五个角色。** 读者记不住。第一章有名有姓的角色控制在三个以内。

## 检查方式

写完前三章，逐条问：

1. 第一章前三百字里，有没有一个具体的、能一句话说清的麻烦？
2. 主角有没有**主动做出选择**，而不是被推着走？
3. 第三章结尾，有没有一个明确的、尚未解决的问题？
4. 三章里有没有出现读者必须记住却记不住的信息量？

任何一条答不上来，就是这三章还没写对。

## 边界

这套只管开篇。第四章之后靠的是主线推进和爽点节奏，不是这套规则。
