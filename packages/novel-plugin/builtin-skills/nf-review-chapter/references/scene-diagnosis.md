# 五步场景诊断与理想读者复盘速查卡

仅在场景读起来平淡、牵强或停滞时使用；进展自如的场景不必机械拆解。

## 五步场景分析法

1. **界定直接冲突**：分别用「为了……」写清驱动者欲望与对抗力量欲望（对抗者可以是他人、主角内心或环境）；若双方欲望只是相切而非迎头相撞，场景必然缺乏张力。
2. **标注开篇价值**：本场押上台面的核心价值（生/死、信任/背叛、主动/被动等）在开场处于正面还是负面？
3. **拆解潜文本节拍**：忽略字面寒暄，用「施压 / 试探 / 回避 / 亮牌」等行为本质标出每一拍；重复同一招式不算新节拍，沉默与置之不理也是有效反应。
4. **检验结尾价值（剔除非事件）**：对比结尾与开篇价值负荷。如果结尾与开篇毫无变化，即便交代了设定或信息，该场仍属「非事件」，应合并、砍掉或重写冲突。
5. **定位鸿沟转折点**：找出期望与客观结果劈开鸿沟的那一瞬；转折过早会泄气，过晚会前戏拖沓，据此调整欲望或行为。

## 理想读者停顿诊断

- **分心点**：读者最容易跳读的段落，往往是成块背景说明（解释性肿块）或重复打转的过场；优先把两页背景压缩为两段，拆入当下行动。
- **二分病因**：
  - 「自己明白但未写清」→ 补关键动作、路标或前情线索；
  - 「自己也说不清为何如此」→ 属于动机或因果断层，需回到场景设计重构，不要靠堆形容词硬糊过去。
