# 动态存储边界

## 主归属

动态创作事实归叙事记忆。

## 存储内容

- 事件推进
- 时间线
- 角色状态变化
- 关系变化
- 伏笔状态
- 冲突状态
- 写作后产生的 NarrativeEvent

## 不存储内容

- 静态设定
- 风格预设
- 模板
- 节拍
- 未采纳的多版本结果
- 单纯表达差异

## 边界原则

1. 动态事实只有一个主归属：叙事记忆
2. 写作工具产生的事实变更必须走 NarrativeEvent
3. 高风险事实进入 pending
4. 未结算版本不进入叙事记忆
