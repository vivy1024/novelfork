# 静态存储边界

## 主归属

静态参考资料归经纬。

## 存储内容

- 人物
- 地点
- 势力
- 世界规则
- 术语
- 作者备注
- 长期稳定参考资料

## 不存储内容

- 章节正文
- 动态事件
- 角色当前运行时状态
- 伏笔完成度
- 纯临时编辑结果

## 边界原则

1. 经纬只承担静态参考
2. 动态事实不得写入经纬
3. LLM 不应自动覆盖静态设定
4. 经纬变更需要作者意图或明确确认
