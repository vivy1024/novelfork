# 文件系统与 SQLite 策略

## 决策

文件系统作为正文与书籍资源的主语义存储。

SQLite 不再作为章节资源主存储继续扩展。

## 为什么

- 章节正文天然适合文件系统
- 文件系统更容易被用户理解、备份、迁移和查看
- SQLite 继续作为章节主存储会制造双主语义
- 双主语义会导致测试、工具和文档全部变重

## SQLite 可以继续承担的职责

- 通用运行时状态
- 会话记录
- 设置
- 索引
- 诊断日志
- 非正文主语义数据

## SQLite 不应继续承担的职责

- 正式章节正文主存储
- 候选稿/草稿主存储
- 写作中间态主系统

## 清理方向

1. 停止扩展 SQLite 写作资源表语义
2. 文件系统成为正式章节唯一主路径
3. 旧兼容层只作为迁移期存在
4. 文档和测试同步更新为文件系统主语义
