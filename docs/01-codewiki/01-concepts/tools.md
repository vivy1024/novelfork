# 工具层

## 定义

工具是用户体验入口，不是新的业务对象工厂。

工具帮助用户完成写作、分析、修改、比较和结算动作。

## 工具应该做什么

- 读取经纬作为静态参考
- 读取叙事记忆作为动态上下文
- 操作正式章节或文本片段
- 生成建议、版本或变更
- 在需要时触发叙事记忆回写

## 工具不应该做什么

- 新建候选稿 / 草稿体系
- 绕过叙事记忆制造事实
- 绕过用户确认写入预设
- 直接形成新的中间业务对象

## 当前核心工具

- 文风提取
- 选段扩写
- 改写
- 多版本
- 章节结算 / 发布 / 回写

## 设计原则

1. 工具是动作，不是对象
2. 工具输出必须有明确去向
3. 工具结果要么进入正式章节，要么进入版本，要么进入配置建议，要么进入叙事记忆事件
4. 不允许工具重新发明候选稿/草稿中间层

## 当前清理目标

- 将旧候选稿工具迁移为编辑/版本/结算工具
- 将工具命名从对象名改为动作名
- 保留用户体验能力，删除中间对象负担
