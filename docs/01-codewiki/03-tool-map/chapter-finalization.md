# 章节结算

## 定位

章节结算负责把用户确认的文本变化稳定落到正式章节，并触发必要的叙事记忆回写。

不再使用“章节推进”作为产品概念名。

## 输入

- 用户确认的章节内容
- 版本选择结果
- 改写/扩写结果
- 叙事事件候选

## 输出

- 正式章节更新
- NarrativeEvent
- 叙事记忆 pending / applied 结果

## 推荐流程

```text
用户确认文本
  → 写入正式章节
  → 提取或接收 NarrativeEvent
  → reducer 校验
  → applied 或 pending
```

## 禁止事项

- 禁止通过候选稿 accept 流程作为唯一结算路径
- 禁止把章节结算做成新的中间对象层
- 禁止绕过叙事记忆直接改变动态事实
