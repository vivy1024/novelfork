# 选段扩写

## 定位

选段扩写是编辑工具，直接服务于用户写作体验。

## 输入

- 当前章节
- 用户选中片段
- 扩写意图
- 经纬参考
- 叙事记忆上下文
- 写作预设

## 输出

- 扩写后的片段
- 可应用的文本变更
- 必要时生成版本
- 必要时生成叙事记忆事件

## 应用方式

- 直接替换选段
- 插入到选段后
- 形成多版本结果

## 禁止事项

- 禁止生成候选稿对象
- 禁止生成草稿对象
- 禁止绕过用户确认直接覆盖正式章节
