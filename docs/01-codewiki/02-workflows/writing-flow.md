# 写作流程

## 目标

写作流程负责从用户意图生成或编辑正式章节文本。

它不再以候选稿 / 草稿作为主路径。

## 推荐流程

```text
用户意图
  → 读取经纬静态参考
  → 读取叙事记忆动态上下文
  → 生成 / 编辑文本
  → 用户确认
  → 写入正式章节或进入多版本流程
  → 产生叙事记忆事件
```

## 输入

- 用户写作意图
- 当前章节文本
- 选中片段
- 经纬参考
- 叙事记忆上下文
- 写作预设 / 模板 / 节拍

## 输出

- 正式章节变更
- 多版本结果
- 叙事记忆事件
- 风格或质量提示

## 不允许的路径

- 写作结果先进入候选稿主系统
- 写作结果先进入草稿主系统
- 写作工具直接制造新的中间业务对象
