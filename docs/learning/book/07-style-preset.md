# 文风预设与自动蒸馏

## 这一步解决什么问题

AI 默认的文笔千篇一律。文风预设告诉它这本书「怎么写」：句子怎么断、对话怎么收、场景怎么铺。写章和划词改写都读同一份预设，所以前后口吻一致。

蒸馏就是从一段参考文字里提炼写法：规则、范文和一组统计数字。最好的来源是你自己满意的旧稿。

## 在哪里点

活动栏点「技能文风」。左侧栏有「写作技能」和「文风」两个标签，文风预设在「文风」里；中间是「文风自动蒸馏」和「文风金库」。

一本书里，文风和写作技能是并列的两样：文风管「怎么写」，写作技能管「用什么方法做」。设定归作品基础，发生过的事归叙事记忆，都不放在文风里。

## 本书文风预设里有什么

「预设名称」；「通用写法（每行一条）」；「基调」；「叙事声音」；「本书创作原则（每行一条）」，这里写你自己的硬约束，比如「不写系统提示音」。

下面是「来源包」：蒸馏或改稿采纳进来的规则和范文。每条标着「可迁移」或「作品专属」，「待审」或「已确认」，并附原文证据。只有已确认、可迁移的规则会进入写作指南。

最下面的「合成指南预览」就是 AI 写作时实际读到的文风指南。改完点「保存文风预设」。

## 推荐使用流程

1. 网页蒸馏：在「文风自动蒸馏」填「来源名称」，把参考文本贴进「粘贴参考文本」，点「预览处理范围」。
2. 看「处理范围」：章节数、字数、预计产出多少条。没问题点「开始蒸馏」，要改点「返回修改」。
3. 等它按章节分批处理。中途失败的批次不影响已完成的，可以点「继续未完成批次」或「重试失败批次」。
4. 审阅「写法规则」和「范文」：看证据，觉得对的点「确认这条」。「统计指纹」只作对照参考。
5. 点「采纳到本书文风预设」。只有你确认过的会被写进去。
6. 对话蒸馏：片段短的话，直接贴给叙述者，说「记住这种写法」或「学学这段」。它会逐条给你看提炼出的写法，只把你点名同意的写进预设。

## 结果去哪里

全部存进这本书的文风预设，每本书一份。叙述者写章时会读文风指南，并按本章是对话、动作还是描写等场景，挑 2 到 4 段已确认的范文当示例。划词改写也会带上这本书的文风。

「作品专属」的条目即使确认了，也只作为来源证据保存，不会进指南，避免把别人书里的人名和情节带进来。

## 常见问题

- 网页蒸馏报错说没有模型：网页蒸馏用「设置 › 模型」里的默认模型，先把它配好。
- 一次出来几十条，看不过来：先确认最有把握的几条就采纳，剩下的以后再审。待审的不会生效。
- 采纳时提示冲突：文风预设在这期间被改过。重新蒸馏或重新载入后再采纳，避免覆盖别人的修改。
- 能拿别人的书来学吗：只学写法，不搬内容；请确认你有权这样使用。优先用你自己的旧稿。
- 「文风」标签里的「从参考样文提取统计」只算句长、对话占比这类数字，不会产出写法规则。完整的学习请用上面的自动蒸馏。

## Agent 查阅提示

- 对话蒸馏：`style.distill_preview` 预览范围 → `style.distill_start` 分批抽取 → `style.distill_status` 读结果 → 作者逐条点名后 `style.distill_adopt`；不得自行采纳。
