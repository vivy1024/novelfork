# 角色声线：让每个人说话不一样

## 这一步解决什么问题

AI 写对白最常见的毛病是：所有人一个腔调，换个名字就分不出是谁在说。声线把一个角色「怎么说话」写清楚，写对白时当作高优先级的约束。

## 在哪里点

活动栏点「作品基础」，在「角色册」里点开一个角色，打开角色卡。卡上有「角色声线」一块，标着「写对白时的高优先级约束」。

「作品基础」就是这本书的经纬，也就是设定库，声线存在角色卡里，不单独放。

## 十项声线

「声音定位」：一句话说清他开口是什么感觉。

句式习惯：「长短句倾向」「口头禅」「停顿习惯」「常用句式」。

「认知滤镜」：他用什么尺子看人看事，决定他先注意到什么。

「绝不会说的句式」：他嘴里绝不会出现的说法。

情绪变化：「愤怒时」「紧张时」「撒谎时」语言怎么变。

每项有三种状态：「待补充」「待审」「已确认」。只有已确认的项会约束写作。

## 推荐使用流程

1. 先把角色卡的基本设定写好并保存。生成草稿读的是已保存的卡。
2. 在「对白样本」里贴几句这个角色说过的话，越像本人越好。可以打开「扫描最近 10 章正文对白」，让它自己去正文里找。
3. 想让模型帮忙补，打开「请模型增补（须附原文依据）」。模型补的每一项都必须能在材料里找到原话，找不到的会被丢掉。
4. 点「生成草稿」。有依据的项变成「待审」，并列出依据；依据不够的保持「待补充」。
5. 逐项看，觉得对就点「确认」，不对就改了再确认。已确认的项以后生成草稿也不会被覆盖。

## 结果去哪里

存在这个角色的角色卡里。叙述者写章时，会按本章出场的角色名和别名，把他们已确认的声线交给模型。

## 最佳实践

- 先给出场最多的两三个主角做声线，配角等出场多了再补。
- 「绝不会说的句式」往往比「会说什么」更管用。

## 常见问题

- 生成后什么都没变：说明没找到新依据。多贴几句对白样本，或先让这个角色在正文里多说几句。
- 确认时提示冲突：角色卡在这期间被改过。点「重新载入」再操作。
- 能让叙述者帮我确认吗：不能。叙述者可以读声线、生成草稿，确认必须你自己在角色卡上点。

## Agent 查阅提示

- `character.voice.read` 读声线与当前注入文本；`character.voice.draft` 只写待审草稿，不能确认。
