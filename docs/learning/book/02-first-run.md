# 第一次使用：配好模型

## 这一步解决什么问题

NovelFork 自己不带 AI。叙述者写章、文风蒸馏、章后结算，都要调用你配置的模型服务。先配好模型，后面的功能才能用。

没配模型时，你仍然可以建书、写正文、整理设定，只是 AI 相关的按钮会报错或没反应。

## 在哪里点

第一次打开会弹出「欢迎使用 NovelFork」，点「配置 AI 模型」即可。关掉了也没关系：作者首页如果显示「AI 模型尚未就绪」，点旁边的「去配置」。

也可以从左侧导航进「设置」。要用到的是两页：「AI 供应商」和「模型」。

## 推荐使用流程

1. 打开「设置 › AI 供应商」，点「添加供应商」。先选接口类型：不确定就问服务商它兼容哪一种，弹窗里每种都有说明。然后填服务商给你的服务地址和密钥，保存。
2. 打开「设置 › 模型」，在「默认模型」里选一个模型，「摘要模型」也选一个（可以和默认模型相同），保存。
3. 在同一页的「模型连接测试」里点「测试模型」，看到模型回了一句话，就说明通了。
4. 想换界面样子，去「设置 › 外观与界面」挑一套「书房主题」：绿格稿纸、书函藏青、夜更烛光，每套都有浅色和深色。

## 结果去哪里

模型配置存在本机，所有书共用。叙述者、网页上的蒸馏和重新结算，默认都用这里选的「默认模型」。

## 最佳实践

- 写正文选你觉得文笔最好的模型；摘要模型可以选便宜、快的。
- 密钥只填在设置里，不要贴进聊天或正文。

## 常见问题

- 点了「测试模型」报错：先回「AI 供应商」检查接口地址和密钥；再确认所选模型确实在这个供应商下。
- 进设置时出现「NovelFork 初始配置」向导：照着走即可。向导要求至少有一个供应商，没有就先去「AI 供应商」加一个再回来。
- 模型列表是空的：说明还没有可用的供应商，先完成第 1 步。
- 更多供应商、模型和用量的通用说明，见学习中心 Runtime 自带的「提供商、模型与额度」。
