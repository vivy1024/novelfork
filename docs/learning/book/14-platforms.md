# 投稿平台写作建议

> 这些是 NovelFork 的写作建议，用于写前检查和投稿风险自检。它们不是平台官方审核规则，也不能替代平台审核。投稿前以平台当天公开的规则为准。

## 它在哪里起作用

写前检查：章字数目标和平台建议对不上时，写作侧栏会出「平台字数」提醒，不挡写作。

保存正文：叙述者写完一章保存时，会顺手做一次单章轻检，只给提醒。敏感词和 AI 味线索都不阻断正式章节保存。

投稿风险自检：见「导出、发布与项目档案」。

## 平台从哪里来

书的平台来自建书十一问的「打算在哪个平台发布」，之后可以在「写作设置 › 基本信息 › 平台」里改。界面上能选番茄小说、飞卢小说、起点中文网和其他。

十一问里选晋江或七猫，目前会按「通用」处理。想按晋江或七猫的口径自检，可以对叙述者说「按晋江的口径做一次投稿风险自检」。

## 各平台写作建议

### 番茄小说（fanqie）

| 项 | 值 |
|---|---|
| 章字数建议 | 1500 / **2200** / 3500 |
| 每章钩子建议 | 至少 1，建议 2 |

- 快节奏：每章至少一个明确推进与一个新钩子。
- 章尾留断点，避免平收。

### 起点中文网（qidian）

| 项 | 值 |
|---|---|
| 章字数建议 | 2000 / **3000** / 4500 |
| 每章钩子建议 | 至少 1，建议 1 |

- 重信息增量与设定自洽，慢热可接受但每章要有增量。
- AI 味线索仅供人工复核，不代表平台审核结论。

### 晋江文学城（jjwxc）

| 项 | 值 |
|---|---|
| 章字数建议 | 2000 / **3000** / 6000 |
| 每章钩子建议 | 至少 0，建议 1 |

- 重人物内心与关系推进，情绪线要连贯。
- 敏感尺度从严，涉及情节需自审。

### 七猫小说（qimao）

| 项 | 值 |
|---|---|
| 章字数建议 | 1500 / **2200** / 3500 |
| 每章钩子建议 | 至少 1，建议 2 |

- 与番茄相近的快节奏口径；章尾钩子必备。

### 通用（generic）

| 项 | 值 |
|---|---|
| 章字数建议 | 1500 / **3000** / 6000 |
| 每章钩子建议 | 至少 0，建议 1 |

- 未指定平台：按书籍自身字数目标执行，仅做基础检查。

## 数字怎么读

章字数三个数是「下限 / 建议 / 上限」。钩子指章末让人想看下一章的东西，比如悬念、反转、新问题。

## 线索的可信度

敏感词线索来自 NovelFork 内置或作者导入的词典，每条带原词、章节、段落和上下文，可信度中等，不是平台的官方违禁词认证。

AI 味线索来自本地特征分数，可信度较低。它不计算 AI 生成比例，也不对应任何平台的阈值。

正文完整性与连续性来自本地检查和章节审计，空章、格式问题、剧情矛盾都会给建议，改不改由你决定。

## 平台名的写法

手动改书籍文件或让叙述者指定平台时，这些写法都认，大小写不限：

| 你填的 | 解析为 |
|---|---|
| tomato / fanqie / 番茄 | 番茄小说 |
| qidian / 起点 | 起点中文网 |
| jjwxc / 晋江 | 晋江文学城 |
| qimao / 七猫 | 七猫小说 |
| feilu / 飞卢 / other / 未填 / 无法识别 | 通用 |

飞卢目前没有单独的建议，按通用处理。

## 常见问题

- 把 AI 味线索当成检测结论：它只是本地的启发式提示，不代表实际 AI 生成比例。
- 把平台建议当平台政策：提交前仍以目标平台当天公开的规则为准。
- 只看结论不看上下文：先看具体原文、段落和建议，再决定改还是留。
