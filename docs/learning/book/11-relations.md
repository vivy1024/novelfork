# 人物关系与正文人名高亮

## 这一步解决什么问题

写到后面，「这两个人现在是什么关系」「他俩之间发生过什么」很难记清。关系网和资料卡把这些从叙事记忆里调出来，查设定不用翻前文。

## 正文人名高亮

打开一章正文，作品基础里有的人名、地名和它们的别名，会带一条虚下划线。鼠标停上去会提示「Ctrl（⌘）+ 点击查看资料卡」。

资料卡有四个标签：「当前状态」「设定」「关系」「变迁史」。当前状态是截至现在仍成立的事，比如境界、所在地、伤势；记错了可以点「纠正」或「作废」。

## 人物关系网

活动栏点「作品基础」，侧栏顶部点「设定图谱」，中间会打开图谱，切到「人物关系」。

图上焦点人物在中间，内圈是和他直接有关系的人，外圈是关系人的关系人。上方可以换「焦点」人物、选「1 跳」或「2 跳」、选「截至」第几章。

连线颜色表示亲疏：紧密、友好、中性、紧张、敌对。线越粗，两人共同经历的事越多。只在同一场出现不算关系。

## 推荐使用流程

1. 先写几章并完成章后结算，关系才会有东西可画。
2. 在「人物关系」里选主角当焦点，看看他身边的人。
3. 点一条连线，看两人的关系史、证据和走向，以及共同关系人。
4. 点一个人看资料，双击把他换成焦点。
5. 数据看起来不全，点「重建索引」，按作品基础和已结算的事实重新整理一遍。

## 结果去哪里

关系网和资料卡都是从作品基础与叙事记忆算出来的，只读，不另存一份。要改关系，改的是叙事记忆里的那条记录或作品基础里的设定。

## 常见问题

- 关系网是空的：还没有结算过的关系事件。先写章、结算，或对老章节重新结算。
- 某个人名没有高亮：作品基础里还没有这个人，或者他在正文里用了一个没登记的称呼。去角色卡里补上别名。
- 以前结算的章节连不上线：旧格式结算的章节要重新结算后才能连线，见「伏笔与记忆」。
