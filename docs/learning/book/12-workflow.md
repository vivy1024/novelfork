# 工作流：按固定工序写一章

## 这一步解决什么问题

平时说一句「写下一章」，叙述者自己决定怎么做。工作流把顺序定死：先做什么、后做什么、哪一步要你确认、不合格打回哪一步。适合想每章都按同一套标准走的时候。

工作流只管顺序。写法看文风，方法看写作技能，都不在这里改。

## 在哪里点

活动栏点「故事推进」，切到「故事画布」标签，中间会打开画布。画布顶部有「推进」「故事树」「执行」，点「执行」，就是「创作工作流 · 执行」。

## 推荐使用流程

1. 先确认右边已经打开了这本书的叙述者对话。工作流由叙述者执行，没有对话就启动不了。
2. 在下拉框里选一个方案，比如内置的「番茄/起点爆款单章连载流」，填上第几章。
3. 点「启动工作流」。叙述者会收到开工提示，按工序往下做。
4. 看运行状态：执行中、等待你确认、受阻、已完成。需要你确认的工序会停下，看完产物点「批准」（门禁工序叫「放行」），不满意点「打回重做」并写清哪里不行，意见会原样交给叙述者。
5. 某道工序受阻，可以「重试本工序」或「跳过」。叙述者没动静，点「叙述者没动静？提醒它继续」。

## 改方案

画布下方是「工作流画布」，可以编辑工序结构：加工序、连线、设汇合和终点。一道工序连出多条线就是并行。

方案分「草稿」和「已发布」。草稿不能运行，结构没问题后点「发布」。想改内置方案，先「复制为草稿」再改。叙述者也能起草方案，同样要你在这里确认发布。

## 结果去哪里

每道工序的产物照常落到书里：正文进正文，结算进叙事记忆。画布下方有「最近的运行」，可以回看每次运行。

## 常见问题

- 「启动工作流」是灰的：选中的是草稿，先发布。
- 提示还没有打开叙述者会话：在右边对话栏新建一段对话再启动。
- 跑工作流时叙述者说某个写入被拦下：越出当前工序的写操作会被拦住，这是正常的。等轮到那道工序再做。
- 工作流只约束小说工具，叙述者自带的通用工具不受它限制。
