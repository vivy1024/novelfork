# 写下一章：写、改、收尾

## 这一步解决什么问题

写章前最怕两件事：不知道这章要干什么，AI 不知道前面发生了什么。写作侧栏把这两件事放在一处检查。条件不够时它会拦住你，并告诉你差什么。

## 在哪里点

在写作台左边活动栏点「写作」（笔的图标）。侧栏最上面是三步：「写」「改」「收尾」。

- 「写」：准备并写下一章。从上到下是就绪条、卷纲、创作罗盘、检查项，最底下是本章目标和写章按钮。
- 「改」：改刚写完的那一章。
- 「收尾」：结算这一章，确认它提出的变化。

侧栏会自动停在该做的那一步：AI 刚写完、你还没改，停在「改」；改完还没结算，停在「收尾」；都做完了，回到「写」下一章。有橙色小圆点的一步表示有事要处理。你也可以随时点别的步。

新书还没有方向时，最上面会是一张引导卡：没答十一问时写「先回答建书十一问」，答过了写「补全本章焦点」。照着点就行。

## 创作罗盘

创作罗盘记的是近 1–3 章的焦点，有四栏：「本章目标」「必须守住」「必须避开」「备注」。

写好后会自动保存，写章时一起交给 AI。本章目标写一件最该推进的事，比如「让林舟通过守门人试炼」。必须守住写不能丢的人设、承诺、伏笔；必须避开写不想要的走向，比如提前揭底。

点「填入本章指示」，会把本章目标抄到最下面的输入框里。

## 检查项怎么看

每一项前面是 ✓、! 或 ×。× 会挡住写章，! 只是提醒。点右边的小箭头能看到「发生了什么」「为什么要看」「建议怎么做」。有「一键修」的可以直接点。

常见的几项：「本章指示」是没写本章目标；「近章记忆」是有正文但没结算过，AI 会不知道前情，一键修会让叙述者补结算；「章摘要」是前面有章节缺摘要，一键修同样是补结算；「待确认事件」是结算提出了要你确认的重要变化；「伏笔到期」是有伏笔该收了；「卷纲」是还没有本卷目标，一键修会生成卷纲草案给你确认；「写作技能」是这本书还没启用任何写作技能，去「技能文风 › 写作技能」打开需要的技能。

## 推荐使用流程

1. 看就绪条：绿色可以写，黄色可以写但有提醒，红色先处理检查项。
2. 在创作罗盘写好本章目标，点「填入本章指示」；或者直接在「第 N 章要发生什么」里写一句（至少 8 个字）。
3. 想先看结构，点「生成蓝图」。叙述者会先给你一份场景蓝图，你确认后再写正文。
4. 想一步到位，点「写第 N 章」。叙述者会先做写前检查，检查不过就停下告诉你缺什么。
5. 写完后侧栏跳到「改」：会告诉你这一章是不是 AI 写的、你改动了多少，点「打开第 N 章正文」去读、去改。本章已经写过时，「写」这一步的按钮也会变成「打开第 N 章正文」。
6. 改完到「收尾」：点「结算第 N 章」，让模型把你改后的正文重新读一遍；下面的「本章提议」逐条确认或驳回；「把改得好的段落存为范文」里勾选你改过的段落。
7. 点「开始写第 N+1 章」回到「写」。

## 结果去哪里

写好的章节存进正文，在「故事推进 › 章节与大纲」的章节树和「资源 › 文件」里都能找到。叙述者的结果卡上点「在画布打开」可以直接打开。

叙述者写完会自动做章后结算：让模型把这一章发生的事记进叙事记忆（正文里已经发生的事）。你自己改过正文后，记忆就可能过期，要在「收尾」里再结算一次。重要的变化出现在「收尾」的「本章提议」里，你点「确认」或「驳回」。不处理也不会挡住写作。

AI 写的原稿还会在文风金库留一份，用来对比你改了哪里，见「文风金库」。

## 常见问题

- 写章按钮是灰的：看按钮上方的提示，通常是本章目标没写或太短，或者检查项里有 ×。
- 「改」「收尾」点不了：还没有写完的章，写完第一章就能用。
- 结算提示没有默认模型：先在设置里配好 AI 供应商并选定默认模型。
- 已经结算过，但觉得上次漏记了：在「收尾」点「强制重新结算（上次漏记时用）」，正文没改也会重新读一遍。
- 想自己排这一章的节奏：展开「本章情节点预算（可选）」，给每个情节点分配字数，写章时会一起交给叙述者。
- 勾选「采用当前焦点的默认目标」是什么意思：你没写本章目标时，用创作罗盘里已有的焦点作为本章方向。
- 试写的几章不想要了：对叙述者说「把第 5 到第 7 章作废」。它会归档这几章正文，清掉这几章记下的事，设定不会动。确认后才执行，别用结算把废稿记进记忆。
- 章字数和平台对不上：「平台字数」提醒来自投稿平台建议，见「投稿平台写作建议」；改每章字数在「写作设置 › 写作参数」。

## Agent 查阅提示

- 写作侧栏的按钮只把本章目标和章号交给叙述者；写章顺序是 `write.preflight` → `scene.spec` → `pipeline.write`，写前检查不过就停下。
- 废稿用 `chapter.discard_range`，补历史章节的记忆用 `memory.settle_range`。
