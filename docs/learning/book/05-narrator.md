# 和叙述者一起写

## 这一步解决什么问题

很多事不用自己去翻面板：问进度、查设定、埋伏笔、改一段话，直接对叙述者说就行。它能读这本书的正文、设定和记忆，也会调用 NovelFork 的小说工具把结果存回书里。

每本书的叙述者只管这本书。它读写哪本书由系统决定，不用你告诉它路径。

## 在哪里点

写作台右边就是叙述者对话栏。活动栏底部的「AI 对话」可以把它打开或收起。对话栏顶部有「会话历史」和「新建对话」：一本书可以开好几段对话，比如一段专门写正文，一段专门讨论设定。

写作侧栏的「写第 N 章」、划词的「续写」「改写」等按钮，其实也是把任务交给这里的叙述者。

## 八个作者入口

写作技能里有八个是给作者直接用的，叫「作者入口」：看进度、写下一章、审这一章、改这段、伏笔、设定、写法记忆、导出。

用法就是说出你要做的事。比如「写到哪了，下一章写什么」「审一下第 12 章」「这段太啰嗦，改一下」「查一下主角的师父是谁」「记住这种写法」。叙述者会照对应技能里的方法做。

这些技能要先在这本书里启用：打开「技能文风 › 写作技能」，列表最前面的「作者入口」，把要用的打开。新书不会自动全部启用。

## 推荐使用流程

1. 一次交代一件事，说清楚要什么结果。比如「给第 8 章写三个章末钩子，让我挑」，比「优化一下」好。
2. 叙述者要改你的书时，会按你的权限设置请你确认。先看它要改什么，再点允许。
3. 看结果卡。写出来的章节可以点「在画布打开」。
4. 重要的决定别只留在对话里：本章目标写进创作罗盘，设定写进作品基础。

## 结果去哪里

写的正文进正文；新设定进作品基础（经纬，也就是设定库）；记下的变化进叙事记忆（正文里已经发生的事）；文风条目进本书文风预设。凡是 AI 从正文里抽出来的设定，都先标为待确认，你确认后才算数。

## 常见问题

- 叙述者不回话或报错：多半是模型没配好，见「第一次使用：配好模型」。
- 聊久了它记不清前面说过的事：对话太长时会被压缩。开「新建对话」重新开始，重要的东西放进创作罗盘和作品基础，新对话也读得到。
- 它说某个工具被拦下了：可能是写前检查没过，或正在跑工作流、这一步不许写。按它转述的原因处理。
- 权限、子代理、对话压缩这些通用功能，见学习中心 Runtime 自带的「叙述者与工作会话」和「工具权限与安全」。

## Agent 查阅提示

- 小说工具都绑定当前书，书籍身份由服务端可信绑定解析，不接受模型传入的路径。
- 机器抽取的设定写 `layer=dynamic`、`status=needs-review`，作者确认后才可升为定稿。
