# 写作 SOP

> 每个场景一条固定动作顺序。照着走能避开绝大多数"写出来不对味、越写越偏"的返工。

所有写入动作都要经 Runtime 权限确认，界面不会替你静默改数据。

## 场景一：写下一章（最常用）

1. 打开工作台侧栏的 **写作** 视图（✍️）。
2. 看**就绪条**：
   - 🟢 绿灯 → 可以写。
   - 🟡 黄灯 → 可以写，但有提醒，值得先扫一眼。
   - 🔴 红灯 → **别写**，先处理阻断项。
3. 展开有问题的检查项，读「发生了什么 / 为什么要看 / 建议怎么做」。能一键修的点「一键修」，它会把请求交给叙述者执行。
4. 在「第 N 章要发生什么」里写**一句**本章目标（至少 8 字）。这一句决定本章走向，比任何设定都重要。
   - 留空则采用当前焦点的默认目标，但需要勾选确认。
5. 点 **生成蓝图** 先看结构，或 **直接写章** 一步到底。

> 也可以在对话里直接说"写下一章"。叙述者同样必须先过 `write.preflight`，preflight 不通过它会停下告诉你缺什么。

## 场景二：续写一本已有的旧书

1. 命令面板（Ctrl+Shift+P）→ **导入旧书 / 拆书**。
2. 提供文本或文件，叙述者用 `pipeline.import_chapters` 导入（默认同时结算记忆并抽取简要设定）。
3. 拆书产物一律落在 **待确认（needs-review）**，不会直接变成 canon。
4. 去经纬工作区「设定」分区逐条过：对的留下并升为 canon，有幻觉的直接改或删。
5. 回写作视图跑一次预检，确认近章记忆已就位。
6. 按场景一开写。

**别跳第 4 步。** 机器抽取一定有噪声，把它当 canon 会污染后续所有章节。

## 场景三：预检报"近章记忆为空"

说明有正文但没结算过记忆，写手会自行编造前情。先判断这些章是什么：

- **是正史，要继续用** → 点「一键修」，或让叙述者 `memory.settle_range` 回填。
- **是废稿，不要了** → 走场景四，**不要**给废稿养正史。

## 场景四：试写了几章，写废了要重开

1. 让叙述者 `chapter.discard_range` 作废该范围（必须 `confirm=true`）。
2. 它会归档正文、清掉范围内的事件与事实、按策略重置伏笔；**不动**经纬里的静态设定。
3. 再跑 `write.preflight`，确认近章记忆已干净。
4. 从场景一重新开写。

## 场景五：中盘防跑偏

- **卷纲**：`outline.volume(action=get)` 看当前卷目标；没有就 `suggest` 生成草案，你确认后再 `set`。当前卷目标会自动进入预检和蓝图。
- **角色弧**：`arc.character` 查谁的成长线停滞或回退了。
- **伏笔**：预检会报 `hooks-overdue`；伏笔看板在「工具」视图。

## 场景六：发布前

1. `publish.check` 做投稿风险自检：敏感词线索、AI 味线索、正文完整性、连续性及其规则来源。
2. 按结果处理：
   - **ready** → 本地未发现明显线索，仍由作者决定是否投稿。
   - **has-warnings** → 查看提醒和上下文，再决定是否修改。
   - **needs-review** → 有高风险线索，逐条查看正文证据并人工复核。
3. 平台写作建议与规则边界见[平台写作卡](./26-platform-writing-cards.md)。

> `pipeline.write` 保存前也会做单章轻检，但只返回提示；敏感词与 AI 味线索不会因平台口径拒绝保存。

## 不该做的事

| 别做 | 为什么 | 改做 |
|---|---|---|
| 红灯硬写 | 缺上下文时写的是编造前情，返工更贵 | 先处理阻断项 |
| 拆书产物直接当 canon | 机器抽取有幻觉，会污染后续所有章 | 逐条确认后再升 canon |
| 给废稿结算记忆 | 废稿进正史后，写手会拿它当前情 | 先 `chapter.discard_range` |
| 把章后事实手写进经纬设定 | 设定与进度混在一起，之后分不清哪个是真 | 走叙事记忆，在「进度」分区确认 |
| 靠通用口径投具体平台 | 拿不到该平台字数窗口与敏感尺度 | 填书籍 `platform` |

## 记不住时看哪里

- 当前能不能写：**写作视图**的就绪条。
- 设定 vs 进度：**经纬**视图的两个分区（设定 = 相对稳定，进度 = 随剧情推进）。
- 工具链全貌：[Agent 写作管线](./08-agent-pipeline.md)。
- 平台要求：[平台写作卡](./26-platform-writing-cards.md)。
