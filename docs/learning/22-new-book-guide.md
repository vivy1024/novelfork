# 新书引导（建书十一问）

> 创建新书后自动触发十一问引导，收集创作意图后推荐写作技能并生成经纬骨架。

## 工作原理

1. **创建书籍**：在首页点击"新建作品"，填写书名和简介。
2. **十一问引导**：系统自动展示 11 个结构化问题（题材、受众、主角、核心冲突、世界设定、篇幅目标等）。
3. **AI 推荐写作技能**：根据答案匹配适合的 Writing Skills（如"冲突与悬念分工"、"人物一致性守则"等），作者确认后启用。
4. **生成经纬骨架**：AI 根据答案自动创建经纬条目（角色、世界规则、卷纲草案），标注为 `layer=dynamic, status=needs-review`。
5. **进入写作工作台**：引导完成后刷新资源树，作者可直接开始写第一章。

## 十一问内容

| 序号 | 问题 | 用途 |
|------|------|------|
| 1 | 什么题材/类型？ | 匹配 Writing Skills |
| 2 | 目标平台？ | 合规基线选择 |
| 3 | 预计总字数？ | 卷纲规划 |
| 4 | 主角是谁？ | 角色经纬生成 |
| 5 | 核心冲突？ | 伏笔与弧线种子 |
| 6 | 世界设定关键点？ | 世界规则经纬 |
| 7 | 写作风格偏好？ | Style Skills 筛选 |
| 8 | 更新频率？ | 日更目标配置 |
| 9 | 是否有大纲？ | 卷纲导入 vs 生成 |
| 10 | 已有多少存稿？ | 导入流程触发 |
| 11 | 特殊要求？ | 自定义 Rules 注入 |

## 与写作技能的联动

引导结束后：
- 推荐的 Skills 只是建议，作者确认后由 `handleWritingSkillsWrite` 直接同步到当前项目磁盘。
- Skill 及其关联附件同步到作品的 `.novelfork/skills/<slug>/`；Runtime 会自动发现文件，`book.json` 不保存启用态。
- 作者可在"写作配置 → 技能"中随时调整，面板只对指定项目文件执行添加、删除或刷新。

## 与旧版建书的区别

| 旧版 (v2.x) | 新版 (v3.3+) |
|---|---|
| 10 个自由文本问题 | 11 个结构化问题 + 类型化选项 |
| 直接生成经纬 Markdown 文件 | 生成经纬条目（数据库存储） + Writing Skills 推荐 |
| 无质量验证 | 生成后标注 `needs-review`，作者确认后升 canon |
| 无 Skill 联动 | 自动推荐并启用匹配的写作技能 |
