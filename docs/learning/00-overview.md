# 一页理解 NovelFork

> 你说方向，AI 执行。所有数据存本机，不上传任何内容。

## 它是什么

NovelFork 是本地运行的网文创作工作台。你通过对话告诉 AI 想写什么，AI 帮你规划、写作、审校。你掌控方向和设定，AI 负责产出文字。

## 界面布局

三栏结构：

- **左栏**：资源树 — 书籍、章节、经纬资料、伏笔
- **中间**：画布 — 阅读和编辑章节内容
- **右侧**：叙述者对话 — 你和 AI 交流的主入口

## 5 分钟上手

1. **配置模型**：设置 → 供应商 → 添加 API Key 和地址
2. **创建作品**：左栏「新建作品」→ 填书名、选题材
3. **开始写作**：右侧对话框告诉叙述者你想写什么
4. **审阅结果**：AI 生成的正式章节结果出现在画布中，可继续编辑

## 核心概念

| 概念 | 一句话解释 |
|------|-----------|
| 叙述者 | 右侧的 AI 对话助手，你的写作搭档（每本书自带，不可删除） |
| 经纬 | 世界观/角色/设定的静态设定库，AI 写作时按关键词/章号窗口自动注入 |
| 叙事记忆 | 正文产生的动态事实流（角色状态、关系、伏笔、事件），与经纬分工 |
| 写作技能 (Writing Skills) | 可组合的写作方法论（文风/节奏/钩子/平台），物化后由叙述者加载 |
| 写作管线 | write.preflight → 读取技能 → 叙述者提交 scene.spec 蓝图 → pipeline.write 校验落盘 |
| 三层闭环 | 写前查经纬+记忆+技能 → 写中按三者执行 → 写后结算沉淀 → 下次再查，循环治愈遗忘 |
| 投稿风险自检 | 敏感词/AI 味/格式/连续性证据化汇总，带原文定位，只供人工复核 |
| 套路 | Agent 行为规则集：命令/工具/权限/技能/MCP/Hooks |
| 工具面板 | 全书健康度/质量趋势/文风漂移/伏笔看板/角色弧线/投稿风险自检 |

## 最佳实践

- **先聊再写**：先和叙述者讨论想法、人物、冲突，再动笔
- **经纬越全越好**：AI 能看到的设定越多，生成质量越高；为矛盾状态条目设互斥组、为关联条目设关联关系
- **启用写作技能让 AI 守规矩**：在写作配置中按需组合 Style / Plot / Character 类 Skills
- **善用注入预览**：经纬侧栏的「AI 注入预览」可按章查看叙述者会拿到哪些设定
- **首次引导向导**：首次进入设置时会弹出 6 步引导（供应商→模型→网络），跟随完成即可上手

## 常见坑

| 问题 | 解决 |
|------|------|
| 叙述者无响应 | 设置页检查供应商状态，确认 API Key 有效 |
| AI 写的和设定矛盾 | 检查经纬条目是否已创建并开启 AI 参与 |
| 生成太慢 | 经纬条目过多撑爆上下文，精简不相关条目或收紧 Token 预算 |
| 技能没生效 | 确认技能已启用物化，且写前叙述者用 Skill 工具读取过（preflight 会提示缺失） |
