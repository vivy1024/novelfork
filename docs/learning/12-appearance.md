# 外观与界面

> 定制 NovelFork 工作台的视觉风格与布局行为。

## 主题

| 模式 | 说明 |
|------|------|
| 浅色 | 白底黑字 |
| 深色 | 暗底亮字（默认推荐，长时间写作护眼） |
| 跟随系统 | 自动随操作系统深色模式切换 |

设置路径：设置 → 外观与界面 → 主题。

## 侧栏可配置显示/收纳

侧栏左下角的全局导航入口支持自由配置：
- **右键任意入口** → 切换为"显示"或"收纳"
- 收纳的入口折叠在"已收纳 (N)"按钮下，点击展开
- 配置持久化到本地 localStorage，跨会话保持

默认显示：叙述者列表、套路、知识库、群聊  
可收纳：定时任务、学习中心等低频入口

## 字体与间距

在设置 → 外观中可调整：
- 界面字体大小（默认 14px）
- 代码字体（Geist Mono）
- 编辑器行高

## 其他偏好

| 偏好 | 说明 |
|------|------|
| 自动加载历史消息 | 打开叙述者会话时是否自动加载旧消息 |
| 快速模式默认 | 新会话是否默认启用快速模式 |
| Markdown 自动换行 | 消息中 Markdown 段落是否自动折行 |
| 代码块自动换行 | 代码块是否自动折行（或水平滚动） |
