# 第 5 课：伏笔的埋与收

## 核心道理

伏笔是一个先说出口的承诺：读者现在看到一个细节，将来会发现它很重要。

埋得好的伏笔，第一次读时自然得不起眼，回头看时恍然大悟。收得好的伏笔，让读者觉得「原来如此」，而不是「作者临时想出来的」。

## 怎么埋

藏在有别的用处的地方。一段对话、一个动作、一件道具，在当下就有作用，同时又埋着以后的意思。

重要的伏笔要提两三次，每次换个角度，免得读者彻底忘掉。

## 怎么收

收的时候，让读者能对上前面的细节。

回收最好伴随一次反转或一次情绪爆发。

收完要有后果：它应该改变人物接下来的选择。

## 怎么管账

长篇最怕伏笔烂尾。每埋一个，就记下埋在第几章、打算在第几章收。

到期收不了，就再推进一点，或者明确放弃。不能让它无声无息地消失。

## 常见毛病

- 伏笔太显眼，一出来读者就猜到结局。
- 伏笔太隐蔽，收的时候读者根本不记得。
- 埋了就忘，几十章后前后矛盾。
- 收尾靠临时冒出的新设定，前面没有任何交代。
- 一次收太多，读者来不及消化。

## 小练习

一、列出书里所有还没收的伏笔，每条写上埋在第几章、打算第几章收。

二、挑一个伏笔，设计一次「中途露面」：在收之前再出现一次，换一个角度。

三、写一段回收的场面，要求读者能指出它对应前文的哪一句。

## 在 NovelFork 里练

对叙述者说「在这章埋个伏笔：某某，第 20 章前收」，它会先给你看方案，再写进经纬的伏笔条目。

故事画布「下一章」页的伏笔账本列出超期和临近的伏笔（活动栏「故事推进」里点「打开故事画布」），写作侧栏也会提醒「伏笔到期」，点「一键修」直接打开它。

提醒的快慢在「写作设置」的「伏笔提醒阈值」里调。详见「伏笔与记忆」。
