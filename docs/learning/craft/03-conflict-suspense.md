# 第 3 课：冲突与悬念

## 核心道理

冲突是两股力量顶在一起：人和人，人和规矩，人和他自己。悬念是读者心里悬着的问题：他能不能成，那个人是谁，接下来会怎样。

冲突让读者站队，悬念让读者翻页。两者要分工：冲突尽量简单直白，读者一眼看懂谁跟谁过不去；悬念尽量藏得巧，答案要落在读者想得到、又没想到的地方。

## 好冲突的样子

双方都有想要的东西，而且不能同时得到。

对手有真本事，会反击，不是等着被打的木桩。

代价看得见：输了会失去什么，读者清楚。

## 悬念怎么做

先给问题，过一阵再给答案。

答一个问题的同时，开一个新问题。

利用信息差：读者知道而角色不知道，读者会紧张；角色知道而读者不知道，读者会好奇。

## 常见毛病

- 反派是纸片人，一碰就倒，主角赢得没有分量。
- 冲突全靠误会撑着，一句话就能说清，读者只会着急上火。
- 悬念一直不揭，拖到读者忘了，或者烦了。
- 一次抛出太多问题，读者抓不住主线。
- 答案来得太巧，靠天降好运解决问题。

## 小练习

一、替你书里的主要对手写一段他自己的道理：他为什么觉得自己是对的？

二、列出读者读到最新一章时，心里悬着的所有问题。每条后面写上你打算在第几章回答。

三、找一个靠误会维持的冲突，改成双方都知情、只是利益不同。

## 在 NovelFork 里练

建书后叙述者会追问「主要对手是谁、他有什么反击能力」，别随便答。

悬着的问题可以当成伏笔记进经纬，到期会提醒你，见「伏笔与记忆」。

可以启用「冲突与悬念分工」技能。「故事推进 › 故事画布」里的「推进」能看每条剧情线停在哪一章。
