# 第 7 课：场景与描写

## 核心道理

描写不是装饰，是让读者「在场」。读者要的不是面面俱到，而是几个准确的细节，剩下的画面他会自己补全。

## 怎么挑细节

挑这个场景独有的、和人物此刻处境有关的。

同样一间屋子，逃命的人先看见门和窗，饿了三天的人先看见桌上的馒头。通过人物的眼睛和身体来写，就同时写了人。

别只写看见的。声音、气味、冷热、手上的触感，常常更让人相信。

## 场景要有变化

一个场景开头和结尾，人物的处境或关系应该不一样。没有变化的场景，考虑合并或者删掉。

描写放在节奏慢下来的地方。紧张的时候，一两笔就够。

## 常见毛病

- 大段静止的描写，读者只会跳过去。
- 堆抽象的形容词：美得惊心动魄，气势磅礴。
- 细节都是通用的，放进任何一本小说都成立。
- 描写和人物无关，像一台没人拿着的摄像机在转。
- 场景写完了，人物的处境没有任何变化。

## 小练习

一、选一个写过的场景，删掉所有形容词，再只加回三个具体的细节。

二、同一个地点，从两个处境不同的人眼里各写一百字。

三、在一场戏里加进一个不是「看见」的细节：一种声音、一股气味，或一次冷热变化。

## 在 NovelFork 里练

选中一段描写，点「扩写」会交给叙述者在感官、动作或环境上补细节；点「精简」会删掉多余的修饰。

地点和世界的固定设定放进「作品基础」的「世界录」，写到时 AI 会按需去查。

在文风金库里把你改得好的描写段落「采纳为范文」，场景选「描写」，下次写同类场景会优先参考它。
