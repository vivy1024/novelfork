# 平台写作卡

> 不同平台对章长、节奏和尺度的要求差别很大。NovelFork 把这些口径做成结构化 profile，让写前预检和发布自检能直接用，而不是靠作者记在脑子里。

平台由书籍的 `platform` 字段解析（`publishPlatform` 可显式覆盖）。写作卡不是硬规则，除敏感词阻断外都是提醒。

## 各平台口径

### 番茄小说（fanqie）

| 项 | 值 |
|---|---|
| 章字数 | 1500 / **2200** / 3500（最少 / 建议 / 最多） |
| 每章钩子 | 至少 1，建议 2 |
| AI 率容忍 | 20% |
| 敏感词阻断 | 是 |

- 快节奏：每章至少一个明确推进与一个新钩子。
- 章尾留断点，避免平收。

### 起点中文网（qidian）

| 项 | 值 |
|---|---|
| 章字数 | 2000 / **3000** / 4500 |
| 每章钩子 | 至少 1，建议 1 |
| AI 率容忍 | **0（零容忍口径）** |
| 敏感词阻断 | 是 |

- 重信息增量与设定自洽，慢热可接受但每章要有增量。
- AI 味零容忍口径：写后必做去 AI 与人工复核。

### 晋江文学城（jjwxc）

| 项 | 值 |
|---|---|
| 章字数 | 2000 / **3000** / 6000 |
| 每章钩子 | 至少 0，建议 1 |
| AI 率容忍 | 5% |
| 敏感词阻断 | 是 |

- 重人物内心与关系推进，情绪线要连贯。
- 敏感尺度从严，涉及情节需自审。

### 七猫小说（qimao）

| 项 | 值 |
|---|---|
| 章字数 | 1500 / **2200** / 3500 |
| 每章钩子 | 至少 1，建议 2 |
| AI 率容忍 | 20% |
| 敏感词阻断 | 是 |

- 与番茄相近的快节奏口径；章尾钩子必备。

### 通用（generic）

| 项 | 值 |
|---|---|
| 章字数 | 1500 / **3000** / 6000 |
| 每章钩子 | 至少 0，建议 1 |
| AI 率容忍 | 20% |
| 敏感词阻断 | **否** |

- 未指定平台：按书籍自身字数目标执行，仅做基础检查。

## 平台名怎么写

书籍 `platform` 支持中英文别名，大小写不敏感：

| 你填的 | 解析为 |
|---|---|
| `tomato` / `fanqie` / `番茄` | 番茄小说 |
| `qidian` / `起点` | 起点中文网 |
| `jjwxc` / `晋江` | 晋江文学城 |
| `qimao` / `七猫` | 七猫小说 |
| `feilu` / `飞卢` / `other` / 未填 / 无法识别 | 通用 |

飞卢目前没有独立 profile，按通用口径处理。

## 它在哪里生效

**写前预检**（`write.preflight`）会带上平台标签，并在书籍章字数目标与平台窗口不符时给 `platform-target-mismatch` 告警。这是提醒，不阻断。

**保存正文时**（`pipeline.write`）做单章轻检，默认只提醒。只有在平台 `blockOnSensitiveBlock=true` 且命中阻断级敏感词时，才会 `publish-blocked` 不保存 —— 这是唯一会因平台口径拦住保存的情况。

**发布自检**（`publish.check`）做四个维度：敏感词、AI 率、格式、连续性，按平台口径给出 ready / has-warnings / blocked。

## 常见坑

- **把 AI 率容忍当承诺**：`aiRatioTolerance` 是估算口径，不是平台官方阈值。起点写 0 表示"按零容忍对待"，不代表存在一个官方 0% 检测。
- **靠通用口径投稿具体平台**：没填 `platform` 就拿不到该平台的字数窗口和敏感尺度，发布自检也只做基础检查。
- **指望自检替代人工过审**：敏感词与 AI 率都是本地启发式判断，最终以平台实际审核为准。
