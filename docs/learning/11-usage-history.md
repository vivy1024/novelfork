# 使用历史与 Token 账单

> 追踪 AI 模型的 Token 消耗、请求频率、响应耗时与费用趋势。

## 功能概览

使用历史面板（设置 → 使用历史）提供：

| 功能 | 说明 |
|------|------|
| **筛选条件** | 按供应商、模型、请求类型、时间范围过滤 |
| **统计卡片** | 请求数、Token 总数（输入/输出拆分）、缓存读/写、推理 Token、总费用、平均耗时、首 Token 时间 |
| **时间序列图表** | Recharts 柱状图，按小时/天/月聚合，左轴 Token、右轴请求数/错误数 |
| **请求明细表** | 分页列表，点击可查看单次请求的完整详情（模型、Token、耗时、状态码） |

## 数据来源

- 后端从 SQLite `api_request` 表聚合，由 Runtime 在每次模型调用时自动记录。
- 时间序列由 Runtime 服务端按 granularity（hour/day/month）桶化后返回。
- NUG 反代的使用量通过 NUG 专属 API 独立查询（含通道级拆分）。

## 粒度切换

| 粒度 | 适用 |
|------|------|
| 小时 | 近 24h 调用密度分析 |
| 天 | 近 30 天日均消耗 |
| 月 | 长期费用趋势 |

## 费用计算

费用由各供应商 API 返回的 `usage.cost` 或按 Token 单价估算（部分供应商不返回精确费用）。
费用列显示美元 (USD) 单位，精确到 4 位小数。

## 常见问题

| 问题 | 原因与解决 |
|------|-----------|
| 费用显示 "—" | 该供应商未返回 cost 字段 |
| 请求数量远大于章节数 | 包含工具调用、Context Compact、Sub-agent 等内部请求 |
| 403 无权查看 | 需要 Runtime 管理员角色 |
