# 路线与任务

本文件是 NovelFork 当前路线的任务清单；依据见 [参考项目学习（2026-09）](./90-参考资料/参考项目学习-2026-09.md)。任务按阶段推进，每项写明完成标准；与当前用户指令冲突时以用户指令为准。

## 定位（2026-09-28 与作者确认）

- NovelFork 面向公开用户发布。
- 上游 NarraFork 不做小说方向功能；团队协作由官方插件 `NarraFork/narrator-team` 提供（宿主 0.7.7+）。
- **边界**：通用能力一律归 Runtime（设置、通知、用量、插件、Git、终端、知识库、搜索、定时任务、套路、非章节文件的编辑与回退），NovelFork 只负责嵌入与主题；NovelFork 只做小说领域（书籍、章节、经纬、叙事记忆、写作管线与领域工具、写作工作台与画布、书房主题）。OpenWrite 已按同样的边界改成宿主插件，佐证这条路可行。
- **护城河是两条核心链路**：
  - 人味链：蒸馏文风 → 文风预设 → 写作 → 人文化 → 作者修订回流 → 检测验收；
  - 记忆链：实体身份 → 正文接纳 → 事实、状态与关系 → 故事推进。

## 执行规则

- 学机制不抄原文：PlotPilot（Commons Clause）、笔枢 / Scriverse / InkOS（AGPL）、MuMuAINovel（GPL）的代码与提示词不进仓库；OpenWrite（Apache-2.0）与 `oh-story`（MIT）改编时保留署名与许可声明。
- 验证按 CLAUDE.md：写数据用隔离实例；前端用浏览器实测；发版用当次 EXE 核验。
- T3.2、T3.4 与其余阶段互不依赖，可随时穿插。

2026-09-29 按作者要求并行推进：主线 T2.1 文风预设；独立子任务 T3.4 技能引用、T6.2 保存可靠性、T1.1b PostgreSQL 核查。共享文件由主线集成，完成状态按代码与实际验证更新，不因子代理报告而直接标完成。

同日查看了炼笔智作的登录后界面与拆文范本，见 [交互观察](90-参考资料/炼笔智作-交互观察-2026-09.md)。后续 T2.2 优先闭环“输入与切章预览 → 分批处理 → 证据审阅 → 采纳为本书预设”；T4.5 / T5 面向作者提供任务向导，底层复用现有画布配方与运行记录。没有进行付费生成或检测，不以网页展示证明模型效果。
