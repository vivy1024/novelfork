# 02 - 用户指南

NovelFork Studio 使用指南。

## 安装启动

### 方式一：下载 exe（推荐）

1. 前往 [GitHub Releases](https://github.com/vivy1024/novelfork/releases)
2. 下载 `novelfork-vX.Y.Z-windows-x64.exe`
3. 双击运行，浏览器自动打开 `http://localhost:1422`

### 方式二：源码构建

```bash
# 前置条件：Bun 1.2+, Git
git clone https://github.com/vivy1024/novelfork.git
cd novelfork
bun install
bun run dev        # 开发模式，热重载
# 或
bun run compile    # 编译为单 exe
```

## 首次配置

启动后进入设置页：

1. **模型供应商** — 添加 API 端点（支持 Anthropic / OpenAI 兼容 / 自定义）
2. **API Key** — 填入密钥，本地 SQLite 加密存储
3. **默认模型** — 选择对话使用的主模型
4. **小说预设**（可选）— 选择写作风格/长度/语言偏好

## 创作基本流程

### 1. 建书

- 侧栏点击「新建书籍」
- 填写书名、简介、类型标签

### 2. 设定（经纬系统）

- 进入经纬面板，创建设定条目
- 16 个分类：角色/势力/地点/物品/技能体系/世界规则...
- 设置优先级（核心/相关/参考/自动）
- AI 写作时自动注入相关设定

### 3. 写作

- 在对话中描述你想写的内容
- AI 通过管线自动：驾驶舱快照 → 读取设定 → PGI 追问 → 场景规格 → 生成正文
- 候选稿出现后可：采纳 / 重写 / 变体 / 行内编辑

### 4. 审阅

- 自动运行对抗式审查（连续性/叙事/文本 3 视角）
- 严重度门禁：S1 阻断 / S2 自动修订 / S3-S4 警告
- 手动触发：一致性检查、健康报告、冲突图

## 套路页功能

套路（Routines）是自动化能力的配置中心：

| 功能 | 说明 |
|------|------|
| 命令 (Commands) | 自定义 `/` 命令，绑定到特定提示词 |
| 技能 (Skills) | 可复用的 Agent 技能模板 |
| 提示词 (Prompts) | 系统提示词模板管理 |
| MCP 服务器 | 外部工具集成（Model Context Protocol） |
| 钩子 (Hooks) | 事件触发的自动动作（写前/写后/审计后） |
| 规则文件 | 项目级规则（.novelfork/rules/*.md） |

## 快捷操作

| 操作 | 说明 |
|------|------|
| `Ctrl+Enter` | 发送消息 |
| `Ctrl+Shift+N` | 新建会话 |
| 拖拽文件 | 作为附件发送 |
| `@` 提及 | 引用特定设定条目 |

## 数据存储

所有数据存储在本地：
- 数据库：`~/.novelfork/data.db`（SQLite）
- 配置：`~/.novelfork/user-config.json`
- 日志：`~/.novelfork/logs/`
