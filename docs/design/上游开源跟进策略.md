背景：上游 Runtime 已开源（[NarraFork/NarraFork](https://github.com/NarraFork/NarraFork)，MPL-2.0，公开历史全量重写，与私有线不相交，无 tag、无 Release）。本文记录跟进策略的拍板结论；升级技术评估见 [Runtime-0.8.3-升级评估.md](Runtime-0.8.3-升级评估.md)。

## 一、MPL 源码提供

- 公开源码仓：**[NarraFork/novelfork-runtime](https://github.com/NarraFork/novelfork-runtime)**（2026-10-08 建）。
  - 当前形态：2 个提交 = 公开 v0.7.12 原树 + fork 定制 delta（49 新增 + 92 修改 + 6 个三方移植文件，与升级评估的 fork 层分类精确互证）。不含私有线提交与开源前消毒集内容。
  - 对应本仓库 v0.0.4 发行（NOTICE 已指向；Release 说明须附此链接，属 MPL §3.2(a) 动作）。
  - 私有血统分支（novelfork/upgrade-*、integration-v0.6.6 等）**永不推公开**：含开源前未消毒历史。
- 快照纪律：按产品版本打 `source/vX` 分支，只追加不 force-push；本地 `tmp/novelfork-runtime-public/` 留镜像。

### 转 fork：已完成（2026-10-09）

- 作者授予 `delete_repo` 后执行：删旧 standalone 仓 → `gh repo fork NarraFork/NarraFork --org NarraFork --fork-name novelfork-runtime` → 重推全部快照分支。API 验证 `fork: true`、`parent: NarraFork/NarraFork`、public。
- 分支现状：`main`（fork 自带的上游主线）+ `master` 与 `source/v0.0.4`（同指 v0.0.4 快照 = 公开 v0.7.12 原树 + fork delta）+ `novelfork/upgrade-0.8.3` 与 `source/v0.0.5`（同指 0.8.3 移植结果）。
- 删前全量分支已留存于本地镜像 `tmp/novelfork-runtime-public/` 的 `refs/local-backup/*`，重推后零丢失。
- 收益：上游同步 `gh repo sync`、跨仓 PR、网络图徽标即来源公示。

## 二、跟进节奏

- 锚点：上游无 tag，唯一可靠锚是 main 上的 `release: vX.Y.Z` 提交（0.8.3 = `be624040`）。例行：`git fetch upstream-public && git log --grep='^release: v' upstream-public/main`。
- 节奏：按 NovelFork 版本窗口评估（发版前做一次 0.8.3 式评估），辅以周观（fetch + `package.json` version 比对）。不建议每版必追：0.7.12→0.8.3 是 201 提交 / 1615 文件量级，月级窗口合理。
- 每次评估加查：上次基点是否仍是公开历史祖先（防公开线再次重写）。

## 三、切公开线后的流程改动（0.8.3 窗口执行）

1. `UPSTREAM.lock.json`：`repository`/`remote` → `NarraFork/novelfork-runtime`；`branch` 统一 `novelfork/integration-v<公开版本>`；provenance 增 `publicBase`（release 锚点）与 `virtualBase`（首次树级移植记 `3ac2d0df`）。sync 脚本只用 `remote`/`branch`/`commit`/`tree`，逻辑零改动。
2. 宿主库：`upstream` remote 改指 `NarraFork/NarraFork`；私有仓留档。CLAUDE.md 升级流程段落届时同步改写。
3. 边界检查措辞已改（2026-10-08）：公开渠道指 NarraFork/novelfork-runtime，不再提私有仓。

## 四、0.8.3 升级排期

- 结论：**v0.0.4 基线与真书试用留在 0.7.12；0.8.3 树级移植为发版后第一个底座任务（v0.0.5 窗口）**。
- 顺移判据（满足其一即发版前做）：① 试用问题清单出现上游 0.8.x 已修且本地无规避的项；② 距发版有 ≥2 周验证余量。
- 移植第一刀（全部在宿主库 worktree，不写主仓）：从公开 0.8.3 锚点开 `novelfork/upgrade-0.8.3`，先落 49 个 fork 独有文件并对公开基线跑 typecheck；再 82 个单边修改 `git apply -3`；10 个手工冲突按评估报告第六节表格逐项解。
- 验收关卡（每次升级）：与公开纯基线对照 typecheck 与测试、隔离实例冷启动 + 闸门/权限过滤、迁移双路径、Windows EXE 冒烟（嵌入面板/权限弹窗/Monaco 主题）、`RUNTIME_WORKER_ENTRIES` 契约（0.8.3 新增 ≥6 Worker）、MPL 关（物化树与同版 `source/vX` 分支 tree-diff 为空）。
